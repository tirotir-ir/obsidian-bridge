# Obsidian Bridge

Send selections and current Markdown files from VS Code to a local Obsidian vault.

**Created by [Daryoush Alipour Tirotir](https://github.com/tirotir-ir)**

- [VS Code Marketplace publisher](https://marketplace.visualstudio.com/publishers/daryoushalipourtirotir)
- [GitHub](https://github.com/tirotir-ir)

## Quick start

Set `obsidianBridge.vaultPath` to your vault, for example `C:\\O\\others`. Then select text and run one of the commands from the editor context menu or Command Palette.

The extension creates and updates local Markdown and `.canvas` files only. The optional **Obsidian Bridge Companion** plugin can identify the active Obsidian note or Canvas via an authenticated `127.0.0.1` connection.

See the project root `README.md` in the delivered source archive for the complete English installation guide and configuration examples. The project is maintained at [tirotir-ir/obsidian-bridge](https://github.com/tirotir-ir/obsidian-bridge).
